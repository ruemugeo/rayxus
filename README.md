# Rayxus

> A modular civilization simulation engine.

## Vision

Rayxus is a professional simulation engine designed to simulate believable civilizations, societies and worlds.

It is **not** a game.

The engine is built around:

- Modularity
- Explainability
- Scalability
- Portability
- Long-term maintainability

---

## Tech Stack

- TypeScript
- React

- WebGPU
- Tailwind CSS
- shadcn/ui
